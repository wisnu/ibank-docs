# Dokumentasi Sistem

Selamat datang di portal dokumentasi sistem. Dokumentasi ini mencakup berbagai kelompok aplikasi dan modul dalam ruang lingkup sistem.

## Struktur Dokumentasi

### Product Requirements Documents (PRD)
Dokumen kebutuhan produk dan spesifikasi untuk setiap modul sistem

### Functional Specification Documents (FSD)
Spesifikasi fungsional detail untuk fitur-fitur sistem

### Technical Specification Documents (TSD)
Spesifikasi teknis untuk panduan implementasi

### Test Documentation (TEST)
Dokumentasi pengujian untuk quality assurance

---

## Direktori Utama

Berikut adalah direktori utama pada portal dokumentasi ini:

### 1. iBank
Berisi dokumentasi sistem core banking iBank. Meliputi modul General Ledger, Financing, dan Funding.

### 2. BJBS
Berisi dokumentasi untuk spesifikasi dan kebutuhan aplikasi terkait ekosistem BJBS (misalnya: Fingerscan, dll).

### 3. BCAS
Berisi dokumentasi untuk ruang lingkup sistem BCAS.

---

## Navigasi

Gunakan sidebar di sebelah kiri untuk menjelajahi semua dokumentasi yang tersedia berdasarkan hierarki direktori utama. Anda juga dapat menggunakan fitur pencarian untuk menemukan topik spesifik.

## Konvensi Penamaan

- **PRD**: Product Requirements Document
- **FSD**: Functional Specification Document
- **TSD**: Technical Specification Document
- **TEST**: Test Documentation
