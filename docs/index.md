# Dokumentasi iBank

Selamat datang di portal dokumentasi sistem core banking iBank. Dokumentasi ini mencakup semua aspek dari sistem perbankan kami termasuk modul General Ledger, Financing, dan Funding.

## Struktur Dokumentasi

### Product Requirements Documents (PRD)
Dokumen kebutuhan produk dan spesifikasi untuk setiap modul sistem

### Functional Specification Documents (FSD)
Spesifikasi fungsional detail untuk fitur-fitur sistem

### Technical Specification Documents (TSD)
Spesifikasi teknis untuk panduan implementasi

### Test Documentation (TEST)
Dokumentasi pengujian untuk quality assurance
